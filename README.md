# Blanca Ferrer

Web oficial de Blanca Ferrer, pianista de jazz y compositora.

## Tecnologías

- [Astro](https://astro.build)
- SCSS
- GSAP
- TypeScript

## Requisitos

- Node.js 22.12 o superior

## Uso

```sh
npm install        # instalar dependencias
npm run dev        # servidor de desarrollo en http://localhost:4321
npm run build      # generar la versión de producción en /dist
npm run preview    # previsualizar la versión de producción
```

## Estructura

```
src/
├── assets/       # Imágenes
├── components/   # Componentes (ui, cards, navigation, sections, footer)
├── data/         # Navegación y datos del sitio
├── icons/        # Iconos SVG
├── layouts/      # Layout principal
├── pages/        # Páginas
└── styles/       # Estilos (tokens, base, layout, partials)
```
